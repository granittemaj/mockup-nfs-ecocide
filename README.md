# Slavery Inside Ecocide — review mockup

A visual investigation arguing that forced labour sits *inside* environmental
crime rather than beside it, shown inside the live Not For Sale site chrome.

**Review link:** see the GitHub Pages URL in the repository description.

## What this is

A design and editorial mockup for team review. It is a single self-contained
HTML file: photography, the globe geometry and the site logo are all embedded,
so it needs no build step and no network beyond Google Fonts.

## Interaction

- **The globe** — canvas orthographic projection, drag to rotate, tap a
  country. The 81 countries drawn are those on the 2024 TVPRA list; Mauritius
  is on the list but is too small to draw at this resolution.
- **"Then who holds it?"** — each of the five negations opens to name the roles
  that sit above the worker.

## Known gaps, before this could publish

- Photography is lifted from the social carousel and machine-cropped above or
  below the burned-in captions. Framing is provisional and resolution is capped
  at 740px on the long edge. Production needs the original plates.
- The gloss copy under each line demonstrates the format and needs editorial
  sign-off.
- The globe's per-commodity layer carries only entries checked line by line
  against the ILAB database, so most countries currently show no goods.
- Every figure carries its source, but each still needs a source URL and an
  access date.
